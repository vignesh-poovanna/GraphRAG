Vector Database (Qdrant)

Latent Semantic Search

Vector embeddings capture fuzzy conceptual similarity across 384 dimensions using cosine distance.

  • Strength: Finds relevant passages even when phrasing, synonyms, or vocabulary differ completely.
  • CubeSat Example: Querying "power loss during eclipse" retrieves battery discharge specs even if the word "blackout" was never indexed.
  • Blind Spot: Disconnected from structure—cannot traverse sequential chunks (what happened next) or find 2-hop entity relationships.
Knowledge Graph (Neo4j)

Symbolic Relational Context

Explicit graph nodes connected by typed edges (HAS_CHUNK, NEXT, MENTIONS, RELATED_TO).

  • Strength: Multi-hop reasoning, strict chronological reading via NEXT edges, and domain ontology.
  • CubeSat Example: Knowing that Solar Panels are related to Power Subsystem, which connects to Battery Chemistry.
  • Synergy: Qdrant retrieves the seed entry point; Neo4j expands the surrounding neighborhood for hallucination-free generation!

Retriever Synergy Pipeline

1. User Query: "What happens if battery voltage drops below threshold in safe mode?"
2. Qdrant Vector Search -> Returns top 3 candidate Chunks [chk_12, chk_45, chk_88] via Cosine Proximity.
3. Neo4j Graph Traversal -> Expands [chk_12] -[:NEXT]-> [chk_13] (continuation paragraph) and -[:MENTIONS]-> (Entity: Safe Mode) -[:RELATED_TO]-> (Entity: ADCS).
4. LLM Synthesis -> Synthesizes exact procedure with both semantic nuance AND complete chronological context.
